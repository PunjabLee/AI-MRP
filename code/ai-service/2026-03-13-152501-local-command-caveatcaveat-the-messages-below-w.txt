● You can transfer conversations between machines by copying the data directory.
   Here's how:

  Data Location on Windows

  Claude Code stores conversation data in:
  - Roaming: %APPDATA%\Claude\ (or
  C:\Users\<YourUsername>\AppData\Roaming\Claude\)
  - Local: %LOCALAPPDATA%\Claude\

  Steps to Transfer

  1. On the source machine:
    - Close Claude Code completely
    - Copy the entire %APPDATA%\Claude folder
  2. On the target machine:
    - Close Claude Code completely
    - Paste the folder into %APPDATA%\Claude
    - Overwrite existing files if prompted
  3. Restart Claude Code

  What Gets Transferred

  - Conversation history (SQLite .db files)
  - Settings (settings.json)
  - Project instructions (claude.md)
  - Permission configurations
  - Session data
