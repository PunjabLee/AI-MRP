## 五、两个事项详细方案

### 5.1 事项1：Java-Python数据交换协议

#### 5.1.1 协议设计

```
┌─────────────┐     HTTP/REST      ┌─────────────┐
│  Java后端   │ ←────────────────→ │ Python AI   │
│             │   JSON Request      │   Service   │
│  - 调用预测  │                    │  - 执行算法 │
│  - 获取结果  │   JSON Response   │  - 返回结果 │
└─────────────┘                    └─────────────┘
```

#### 5.1.2 数据格式

**请求格式**:
```json
{
  "request_id": "req_001",
  "timestamp": "2026-03-11T12:00:00Z",
  "type": "PREDICT_DEMAND",
  "data": {
    "item_code": "ITEM001",
    "parameters": {...}
  },
  "callback": {
    "url": "http://java-backend/api/mrp/callback",
    "token": "xxx"
  }
}
```

**响应格式**:
```json
{
  "request_id": "req_001",
  "timestamp": "2026-03-11T12:00:01Z",
  "code": 200,
  "message": "success",
  "data": {...},
  "processing_time_ms": 1200
}
```

#### 5.1.3 实现内容

1. **协议定义文档** - 数据交换格式标准
2. **Java SDK** - HTTP调用封装
3. **Python Wrapper** - 接收处理逻辑
4. **错误处理** - 重试、超时、熔断

---

### 5.2 事项2：预测结果持久化 + 回调机制

#### 5.2.1 架构设计

```
┌─────────────┐      1.请求       ┌─────────────┐
│  Java后端   │ ───────────────→  │ Python AI   │
│             │                   │             │
│  - 调用预测  │   2.处理+存储    │  - 执行算法 │
│  - 存储结果  │ ←───────────────  │  - 持久化   │
│  - 展示结果  │   3.回调/轮询    │  - 回调     │
└─────────────┘                   └─────────────┘
         ↑                               │
         └───────────────────────────────┘
              4.异步回调(可选)
```

#### 5.2.2 实现内容

**预测结果持久化**:
1. 定义结果表结构 (MongoDB/SQL)
2. Python写入逻辑
3. Java查询接口

**回调机制**:
1. 同步响应 (默认)
2. 异步回调 (可选)
3. 轮询机制 (备选)
