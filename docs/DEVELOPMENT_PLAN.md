## Phase 1：MVP（0-3 个月）

### 目标
搭建核心框架，实现基础 MRP 流程可运行

### 里程碑

| 周次 | 任务 | 交付物 |
|------|------|--------|
| W1-W2 | 项目初始化 | 项目骨架、Git、Docker |
| W3-W4 | 领域模型设计 | Domain Model、数据库设计 |
| W5-W6 | 需求管理 | 订单/预测 CRUD |
| W7-W8 | BOM 管理 | BOM CRUD、展开 |
| W9-W10 | 库存管理 | 库存 CRUD、交易 |
| W11-W12 | MRP 引擎 | 核心计算、采购建议 |

### 交付标准
- [ ] 基础 CRUD 可用
- [ ] MRP 计算可执行
- [ ] 采购建议可生成
