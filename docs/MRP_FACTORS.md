## 一、影响因素总览

MRP 计算是一个复杂的系统工程，涉及多个维度的数据交互。以下是完整的影响因素分析框架。

### 1.1 因素分类

```
MRP 计算影响因素
├── 一、基础数据
│   ├── 1.1 物料主数据
│   └── 1.2 BOM 数据
├── 二、库存状态
│   ├── 2.1 现有库存
│   └── 2.2 在途库存
├── 三、需求来源
│   ├── 3.1 销售订单
│   ├── 3.2 销售预测
│   └── 3.3 其他需求
├── 四、业务规则约束
│   ├── 4.1 采购约束
│   ├── 4.2 生产约束
│   └── 4.3 库存约束
├── 五、时间维度
│   ├── 5.1 日历因素
│   └── 5.2 计划时间窗
└── 六、异常处理
    ├── 6.1 数据异常
    └── 6.2 计算异常
```

## 二、详细分析

### 2.1 物料主数据

| 字段 | 英文 | 影响说明 | 优先级 |
|------|------|----------|--------|
| 物料编码 | item_code | 唯一标识 | P0 |
| 物料类型 | item_type | 采购/自制/委外决定供应来源 | P0 |
| 采购提前期 | lead_time | 采购入库所需天数 | P0 |
| 生产提前期 | production_lead_time | 生产所需天数 | P0 |
| 最小起订量 | moq | 供应商最低采购量 | P0 |
| 批量规则 | lot_size_rule | FIXED/LOT_FOR_LOT/EOQ/PERIOD | P0 |
| 安全库存 | safety_stock | 最低库存保障 | P0 |
| 最大库存 | max_stock | 库容限制 | P0 |
| 标准成本 | standard_cost | 成本计算 | P1 |
| 采购单位 | purchase_unit | 采购计量单位 | P0 |
| 生产单位 | production_unit | 生产计量单位 | P0 |
| 检验周期 | inspection_days | 来料检验天数 | P1 |

### 2.2 BOM 数据

| 字段 | 影响说明 | 优先级 |
|------|----------|--------|
| BOM 完整性 | 缺失子件导致计算错误 | P0 |
| BOM 用量 | 父件与子件的数量关系 | P0 |
| BOM 损耗率 | 报废比例影响净需求 | P0 |
| BOM 有效期 | 过期 BOM 导致错误 | P0 |
| 替代物料 | 断料时的替代方案 | P1 |
| 虚拟件 | 非实物料跳过采购 | P1 |
| 配置BOM | 选配物料计算 | P2 |

### 2.3 库存状态

| 字段 | 英文 | 说明 | 优先级 |
|------|------|------|--------|
| 现有量 | on_hand_qty | 当前可用库存 | P0 |
| 已分配量 | allocated_qty | 承诺给销售订单 | P0 |
| 可用量 | available_qty | 现有量 - 已分配 | P0 |
| 冻结库存 | frozen_qty | 锁定不参与运算 | P1 |
| 采购在途 | purchase_qty | 已下单未到货 | P0 |
| 生产在制 | production_qty | 生产中数量 | P0 |
| 委外在途 | subcontract_qty | 委外加工中 | P1 |

### 2.4 需求来源

| 来源 | 状态筛选 | 优先级 |
|------|----------|--------|
| 销售订单 | 只计算已确认订单 | P0 |
| 销售预测 | 按预测百分比计算 | P1 |
| 备件需求 | 设备维护备件 | P2 |
| 安全库存补货 | 维持安全库存 | P1 |

### 2.5 业务规则约束

| 规则类型 | 规则项 | 说明 |
|----------|--------|------|
| 采购 | 最小起订量 MOQ | 采购量必须达到供应商要求 |
| 采购 | 采购批量 | 经济批量/固定批量 |
| 采购 | 供应商交期 | 供应商承诺交期 |
| 生产 | 生产批量 | 最小/最大批量 |
| 生产 | 产能约束 | 生产线最大产能 |
| 生产 | 良率/成品率 | 报废比例 |
| 库存 | 安全库存 | 最低库存 |
| 库存 | 最大库存 | 库容限制 |

### 2.6 日历因素

| 因素 | 影响 |
|------|------|
| 工作日历 | 排除节假日和休息日 |
| 班次安排 | 日/夜班产能差异 |
| 供应商日历 | 供应商休息日影响交期 |
| 物流日历 | 运输时间计算 |

## 三、MRP 参数体系

### 3.1 全局参数

| 参数 | 名称 | 默认值 | 说明 |
|------|------|--------|------|
| planning_horizon | 计划展望期 | 90 天 | 计算多远期限 |
| plan_start_date | 计划起点 | 今日 | 从哪天开始 |
| time_bucket | 时间段精度 | DAY | 天/周/月 |
| allow_negative | 负库存容忍 | false | 是否允许负库存 |
| batch_size | 批处理大小 | 1000 | 单次计算物料数 |

### 3.2 物料级参数

| 参数 | 名称 | 说明 |
|------|------|------|
| lead_time | 提前期 | 采购/生产所需天数 |
| lot_size_rule | 批量规则 | FIXED/LOT_FOR_LOT/EOQ/PERIOD |
| min_lot_size | 最小批量 | 最小起订量 |
| max_lot_size | 最大批量 | 批量上限 |
| safety_stock | 安全库存 | 最低库存 |
| yield_rate | 成品率 | 报废比例 |

### 3.3 批量规则说明

| 规则 | 说明 | 适用场景 |
|------|------|----------|
| LOT_FOR_LOT | 按需批量 | 精确匹配需求 |
| FIXED | 固定批量 | 固定采购量 |
| EOQ | 经济批量 | 最小化总成本 |
| PERIOD | 期间批量 | 按周/月合并 |

## 四、数据完备性检查清单

### 4.1 P0 - 必须具备

| 检查项 | 说明 | 检查SQL |
|--------|------|---------|
| 物料主数据 | 所有物料必须有类型/提前期/MOQ | `SELECT COUNT(*) FROM m_item WHERE item_type IS NULL` |
| BOM 完整性 | 所有成品必须有 BOM | `SELECT COUNT(*) FROM m_item WHERE item_type='FINISHED' AND id NOT IN (SELECT DISTINCT item_code FROM m_bom)` |
| 库存数据 | 库存数据必须准确 | 盘点验证 |
| 销售订单 | 已确认订单才能参与 MRP | `SELECT COUNT(*) FROM t_sales_order WHERE status='CONFIRMED'` |
| 工作日历 | 必须配置工作日 | `SELECT COUNT(*) FROM m_calendar WHERE is_workday=true` |

### 4.2 P1 - 建议具备

| 检查项 | 说明 |
|--------|------|
| 供应商交期 | 供应商主数据必须有交期 |
| 产能数据 | 生产线产能已配置 |
| 安全库存 | 关键物料已配置安全库存 |
| 预测数据 | 销售预测已录入 |

## 五、异常处理策略

### 5.1 数据异常

| 异常 | 检测 | 处理方式 |
|------|------|----------|
| 物料无 BOM | 检查物料类型为"成品"但无 BOM | 跳过并记录日志 |
| BOM 循环引用 | 检测父子件循环 | 报错并终止 |
| 需求日期早于今日 | 需求日期 < 当前日期 | 忽略或标记为逾期 |
| 库存数据负数 | 库存 < 0 | 报警并设为0 |

### 5.2 计算异常

| 异常 | 处理方式 |
|------|----------|
| 计算超时 | 分批计算，设置超时限制 |
| 内存溢出 | 分页处理，释放中间结果 |
| 结果为负 | 设为0并生成采购建议 |

## 六、性能优化

### 6.1 优化策略

| 策略 | 说明 |
|------|------|
| BOM 缓存 | 热点 BOM 数据缓存 |
| 批量计算 | 大数据量分批处理 |
| 增量计算 | 只计算变更物料 |
| 索引优化 | 关键字段建索引 |
| 并行计算 | 多线程并行处理 |

### 6.2 关键索引

```sql
-- 物料索引
CREATE INDEX idx_item_code ON m_item(item_code);
CREATE INDEX idx_item_type ON m_item(item_type);

-- BOM 索引
CREATE INDEX idx_bom_item ON m_bom(item_code);
CREATE INDEX idx_bom_parent ON m_bom(parent_item_code);

-- 库存索引
CREATE INDEX idx_inventory_item ON m_inventory(item_code);
CREATE INDEX idx_inventory_wh ON m_inventory(warehouse_code);

-- 订单索引
CREATE INDEX idx_sales_order_status ON t_sales_order(status);
CREATE INDEX idx_sales_order_due_date ON t_sales_order(due_date);
```
