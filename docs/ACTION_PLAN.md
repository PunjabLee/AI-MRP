### 2.2 数据依赖

| 上游数据 | 下游依赖 | 说明 |
|----------|----------|------|
| m_item | BOM、库存、订单、MRP | 物料是核心主数据 |
| m_bom | MRP 计算 | BOM 展开是 MRP 基础 |
| m_inventory | MRP 计算 | 库存影响净需求 |
| t_sales_order | MRP 计算 | 订单是需求来源 |
| t_demand_pool | MRP 计算 | 需求池合并后计算 |
| t_mrp_suggestion | 采购、生产 | MRP 结果驱动执行 |
