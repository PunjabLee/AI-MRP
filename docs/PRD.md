## 1. 产品愿景与定位

### 1.1 产品定义

**AI MRP** 是一款**可对话式配置的智能物料需求计划系统**。

它将传统 MRP 的复杂配置转化为自然语言对话，通过 AI 理解用户意图，自动完成系统配置、MRP 计算、异常诊断和优化建议，让**任何人都能轻松使用专业级的生产计划系统**。

### 1.2 核心价值主张

| 传统 MRP | AI MRP |
|----------|--------|
| 需要专业人员配置 | 对话式配置，零门槛 |
| 依赖经验调整参数 | AI 自动优化参数 |
| 单一固定算法 | OR 算法 + AI 推荐 |
| 事后分析 | 实时预警 + What-if 模拟 |
| 人找数 | 数找人（主动推送） |

### 1.3 Slogan

**"用对话管理生产，让计划自然发生"**

## 2. 目标用户与场景

### 2.1 目标用户画像

#### 用户 A：中小制造企业主

- **特征**：50 人以下工厂，无专职计划员
- **痛点**：老板凭经验安排生产，经常出错
- **场景**：
  - "王总，本周要出什么货？"
  - "帮我看看还缺什么材料"
  - "客户要提前交货，能行吗？"

#### 用户 B：计划主管

- **特征**：离散制造业，负责生产排程
- **痛点**：多品种小批量，插单频繁，手工排程耗时
- **场景**：
  - "排程优化一下，尽量少换线"
  - "客户订单优先级调整了，重新排"
  - "为什么 A 订单会延期？"

#### 用户 C：供应链管理

- **特征**：负责采购和库存优化
- **痛点**：库存积压与缺料并存
- **场景**：
  - "帮我分析一下库存为什么这么高"
  - "供应商交期要延误，怎么调整计划"
  - "安全库存应该设多少？"

#### 用户 D：数字化转型企业 IT

- **特征**：已有 ERP/MRP，需要智能化升级
- **痛点**：现有系统僵硬，无法满足个性化需求
- **场景**：
  - "把我们的规则对接到 AI MRP"
  - "生成一个定制化的排程方案"

## 3. 产品概念：可对话式配置

### 3.1 什么是对话式配置

**对话式配置**是指用户通过自然语言描述需求，AI 系统理解意图后，自动完成系统配置、数据准备和操作执行。

### 3.2 对话式配置的价值

| 维度 | 传统配置 | 对话式配置 |
|------|----------|------------|
| **学习成本** | 需要培训系统操作 | 会说话就能用 |
| **配置效率** | 小时级/天级 | 分钟级 |
| **灵活性** | 固定表单 | 自然语言无固定格式 |
| **理解力** | 字面理解 | 理解意图 + 上下文 |
| **引导性** | 无 | 主动询问 + 建议 |

### 3.3 对话式配置的能力矩阵

| 能力层级 | 描述 | 示例 |
|----------|------|------|
| **L0: 简单问答** | FAQ 问答 | "什么是 MRP？" |
| **L1: 操作执行** | 单点操作 | "帮我查一下 A 物料的库存" |
| **L2: 流程编排** | 多步骤流程 | "帮我跑一下 MRP" |
| **L3: 智能推荐** | AI 主动建议 | "根据你的历史，建议安全库存调高 20%" |
| **L4: 自主决策** | 自动化决策 | "检测到缺料风险，已自动调整采购计划" |

### 3.4 对话式配置界面形态

#### 形态一：对话窗（推荐）

- 页面侧边或底部悬浮对话窗
- 支持文字输入 + 语音输入
- 实时显示执行结果

#### 形态二：智能助手

- 位于页面顶部/右侧
- 根据当前页面上下文提供建议
- 支持"帮我"、"建议"、"解释"等意图

#### 形态三：命令行（极客模式）

- 支持高级用户
- 支持复杂查询和脚本

| 功能 | 对话式表达 | 优先级 |

| 自动预警通知 | "有风险时主动通知我" | P0 |

**预警类型与响应：**

| 预警类型 | 触发条件 | AI 响应动作 |
|----------|----------|--------------|
| 供应商延迟 | 交期 > 承诺 + 2 天 | 建议换供应商 / 调整计划 |
| 库存不足 | 库存 < 安全库存 | 触发紧急采购 / 调整生产 |
| 需求突变 | 实际需求 > 预测 150% | 重新计算 MRP / 预警 |
| 物流异常 | 运输停滞 > 24h | 触发备货方案 / 通知 |
| 产能不足 | 产能利用率 > 100% | 建议加班 / 外协 / 调整交期 |

**典型对话流程：**

```

是否执行建议？"

#### 4.4.5 影响分析模块

**这是 AI MRP 的核心差异化功能——插单/变更的全面影响分析与智能建议**

##### 4.4.5.1 插单影响分析

| 功能 | 对话式表达 | 优先级 |
|------|------------|--------|
| 插单预分析 | "如果插入这个订单会怎么样？" / "帮我看看插单的影响" | P0 |
| 冲突检测 | 自动检测与现有订单的冲突 | P0 |
| 交期影响 | "新订单会影响哪些订单交期？" | P0 |
| 产能影响 | "车间产能够不够？" | P0 |
| 物料影响 | "需要新增哪些采购？" | P0 |
| 成本影响 | "插单会增加多少成本？" | P1 |
| 一键采纳 | "按建议执行" / "确认插单" | P0 |

| 维度 | 分析内容 | 输出 |
|------|----------|------|

| **产能影响** | 产线利用率变化、是否超产能 | 产能负荷图 |

| **交期影响 | 新订单 vs 现有订单交期对比 | 甘特图 |
| **成本影响** | 加班费、换线成本、紧急采购成本 | 成本对比表 |
| **库存影响** | 库存变化、呆滞风险 | 库存预测 |

### 5.6 沙箱需求

> **AI MRP 特色**：AI 建议需经过沙箱验证再执行，确保安全

#### 5.6.1 沙箱核心价值

| 价值 | 说明 |
|------|------|
| **零风险预览** | 所有计算/分析先在沙箱执行，不影响生产 |
| **完整影响分析** | 调整参数/插单/方案变更前，全面评估影响 |
| **确认后生效** | 用户确认后才同步到生产环境 |
| **多方案对比** | 支持 A/B/C 方案对比，选择最优 |

#### 5.6.2 沙箱功能矩阵

| 功能 | 对话式表达 | 优先级 |
|------|------------|--------|
| **沙箱入口** | "进入沙箱" / "打开模拟环境" | P0 |
| **MRP 预览** | "预览一下 MRP 结果" | P0 |
| **AI 方案对比** | "给我几个方案对比一下" | P0 |
| **参数模拟** | "如果安全库存改成 150 会怎样？" | P0 |
| **影响分析** | "看看这个调整的全面影响" | P0 |
| **应用到生产** | "确认，执行这个方案" | P0 |
| **沙箱记录** | "看看之前的模拟记录" | P1 |

#### 5.6.3 业务模拟分析（参数调优）

**支持的模拟参数：**

| 参数类别 | 参数项 | 影响维度 |
|----------|--------|----------|
| **库存策略** | 安全库存、订货点、最大库存 | 库存持有成本、缺货风险 |
| **采购策略** | 批量、MOQ、提前期 | 采购成本、交期 |
| **生产策略** | 产能约束、换线时间 | 生产成本、交付能力 |
| **MRP 策略** | 批量规则、滚动周期 | 计算结果、计划准确性 |

**影响分析输出：**

| 维度 | 分析指标 |
|------|----------|
| **成本影响** | 库存持有成本、缺货成本、采购成本、总成本变化 |
| **交期影响** | 按时交付率、平均延迟天数、延期订单数 |
| **库存影响** | 库存周转率、平均库龄、呆滞物料数量 |
| **风险预警** | 供应商风险、物料风险、产能风险 |

#### 5.6.4 沙箱隔离方案

| 方案 | 架构 | 适用场景 |
|------|------|----------|
| **独立数据库** | aimrp_prod + aimrp_sandbox | 生产环境 |
| **容器化沙箱** | 独立 PostgreSQL 容器 | 开发/测试 |
| **Schema 隔离** | 同一库不同 schema | 低成本场景 |
