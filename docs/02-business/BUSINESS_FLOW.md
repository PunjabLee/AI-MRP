## 二、子流程

### 2.1 安全库存计算流程

```
┌─────────────────────────────────────────────────────────────────────────────────────┐
│                              安全库存计算                                           │
└─────────────────────────────────────────────────────────────────────────────────────┘

    输入: 物料编码 + 历史需求 + 提前期 + 服务水平
            │
            ▼
    ┌─────────────────────┐
    │ 计算需求标准差        │
    └──────────┬────────────┘
               │
               ▼
    ┌─────────────────────┐
    │ 选择计算方法          │
    │ (统计法/ML/蒙特卡洛) │
    └──────────┬────────────┘
               │
               ▼
    ┌─────────────────────┐
    │ 计算安全库存          │
    │ SS = Z × σ × √LT   │
    └──────────┬────────────┘
               │
               ▼
    ┌─────────────────────┐
    │ 计算再订货点          │
    │ ROP = μ × LT + SS   │
    └──────────┬────────────┘
               │
               ▼
    ┌─────────────────────┐
    │ 计算经济订货量        │
    │ EOQ = √(2DS/H)     │
    └──────────┬────────────┘
               │
               ▼
    输出: 安全库存 + 再订货点 + 订货量
```

## 五、关键业务规则

### 5.1 MRP 计算规则

| 规则 | 说明 |
|------|------|
| 毛需求 | 来自销售订单 + MPS + 独立需求 |
| 净需求 | MAX(毛需求 - 库存 - 在途订单, 0) |
| 安全库存 | 防止缺货的缓冲库存 |
| 批量 | 最小包装量/经济批量 |
| 提前期 | 采购/生产所需时间 |

### 5.2 排程规则

| 规则 | 说明 |
|------|------|
| 优先级 | 紧急订单优先排程 |
| 产能约束 | 不能超过资源最大产能 |
| 工艺路线 | 订单需按工艺顺序加工 |
| 资源冲突 | 同一资源同一时间只能加工一个订单 |
| 交期约束 | 需满足客户交期 |
