## 一、工作任务深度分析

### 1.1 后端完善任务（Priority 0）

| 任务 | 说明 | 依赖 | 工时 |
|------|------|------|------|
| **MRP 业务逻辑完善** | 接入真实数据：BOM展开/需求合并/净需求计算 | MRP框架 | 3d |
| **物料主数据 CRUD** | 物料增删改查 | 公共模块 | 2d |
| **仓库管理** | 仓库 CRUD | 公共模块 | 1d |
| **采购建议生成** | 从 MRP 建议转采购订单 | MRP完成 | 2d |
| **生产建议生成** | 从 MRP 建议转生产工单 | MRP完成 | 2d |
| **集成测试** | 端到端测试 | 以上完成 | 1d |

### 1.2 前端页面任务（Priority 1）

| 任务 | 说明 | 依赖 | 工时 |
|------|------|------|------|
| **项目基础搭建** | Vite + React + Ant Design | - | 1d |
| **布局组件** | 侧边栏/头部/菜单 | - | 1d |
| **订单页面** | 列表/详情/新增/编辑 | 后端API | 2d |
| **BOM页面** | 树形展示/维护 | 后端API | 2d |
| **库存页面** | 库存查询/出入库 | 后端API | 2d |
| **MRP页面** | MRP执行/结果展示 | 后端API | 2d |

### 1.3 AI 对话任务（Priority 2）

| 任务 | 说明 | 依赖 | 工时 |
|------|------|------|------|
| **对话窗 UI** | React 组件 | 前端基础 | 1d |
| **意图识别** | 识别用户意图 | AI服务 | 2d |
| **实体提取** | 提取物料/订单等实体 | AI服务 | 2d |
| **执行路由** | 分发到对应 API | 意图识别 | 2d |
| **结果展示** | 结构化展示结果 | 执行路由 | 1d |

## 二、工作顺序

```
第一阶段：后端完善（1-2周）
├── 1. 完善 MRP 业务逻辑
├── 2. 物料 CRUD
├── 3. 仓库管理
├── 4. 采购/生产建议生成
└── 5. 集成测试

第二阶段：前端开发（3-4周）
├── 1. 项目基础搭建
├── 2. 布局组件
├── 3. 订单页面
├── 4. BOM 页面
├── 5. 库存页面
└── 6. MRP 页面

第三阶段：AI 对话（4周）
├── 1. 对话窗 UI
├── 2. 意图识别
├── 3. 实体提取
├── 4. 执行路由
└── 5. 结果展示

第四阶段：版本发布
└── 创建 release 分支
```

## 三、分支命名规范

根据 Git Flow：

| 分支类型 | 命名格式 | 说明 |
|----------|----------|------|
| **功能分支** | feature/功能名 | 开发新功能 |
| **修复分支** | fix/问题名 | Bug 修复 |
| **发布分支** | release/v版本号 | 准备发布 |
| **热修复** | hotfix/问题名 | 紧急修复 |
| **MVP 分支** | release/mvp-1.0 | MVP 1.0 版本 |
